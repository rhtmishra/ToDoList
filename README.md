✅ ToDoList (ReactJS)
A simple and intuitive To-Do List web app built with ReactJS, using modern React Hooks for state management. Easily add, delete, and keep track of your daily tasks with a clean and responsive UI.

🌟 Features
Add and delete tasks with a single click

Real-time updates with React state and hooks

Minimal and user-friendly design

Fully responsive layout for all screen sizes

🛠️ Tech Stack
ReactJS

React Hooks (useState)

CSS for styling

📁 Getting Started
Clone the repo
git clone https://github.com/rhtmishra/ToDoList.git

Install dependencies
npm install

Start the app
npm start
